虽然 [Clash](/blog/mac-clash-verge-rev-guide/) 系客户端目前大行其道，但在 Windows 平台上，**v2rayN** 凭借着极其轻量的体积、极低的内存占用以及对 V2ray (VMess/VLESS) 等协议的原汁原味支持，依然占据着庞大的守旧派用户市场。

如果您不习惯复杂的[分流规则](/blog/proxy-modes-guide)，只想找一个最简单的工具测个速就能用，v2rayN 是非常好的选择。

## 一、软件获取与安装

*   **唯一安全来源**：请务必前往官方 GitHub 仓库 (`2dust/v2rayN`) 的 Releases 页面下载。切勿使用第三方打包的“汉化版”或“绿色版”。
*   **下载版本**：新手建议下载带有核心的压缩包，通常命名为 `v2rayN-windows-64-with-core.zip`（2026 年最新版本以页面显示为准）。
*   **安装**：下载后，将其解压到**非中文路径**的文件夹（如 `D:\v2rayN`），切勿直接在压缩包内双击运行。右键点击蓝色的 `v2rayN.exe` 图标，以管理员身份运行。

## 二、导入[机场](/blog/what-is-airport-proxy/)订阅

在确保您已经复制了有效的[订阅链接](/blog/what-is-subscription)后：

1.  打开 v2rayN 主界面，点击顶部菜单栏的 **订阅分组 (Subscription group)** -> **订阅设置 (Subscription settings)**。
2.  在弹出的窗口中，点击左上角的 **添加 (Add)** 按钮。
3.  在 **可选地址 (URL)** 一栏中，粘贴您的订阅链接。备注可随意填写。
4.  点击确定保存，回到主界面。
5.  点击主界面顶部的 **订阅分组** -> **更新当前订阅 (不通过代理)**。稍等片刻，主界面的列表就会被各类[节点](/blog/what-is-node/)填满。

## 三、节点测试与选择

导入节点后，我们需要[测试节点速度](/blog/how-to-test-node-speed)并激活：

1.  在节点列表中按下 `Ctrl + A` 选中所有节点。
2.  右键点击，选择 **测试服务器延迟 (TCPing)**。
3.  列表的“延迟”列会出现具体的数字。找到一个延迟较低且未超时的节点。
4.  在该节点上**右键点击**，选择 **设为活动服务器 (Set active server)**。节点颜色会发生变化，并在前面出现打勾符号。

## 四、开启代理上网

最后一步，让电脑浏览器的流量走节点：

1.  在 v2rayN 主界面的最下方状态栏，找到 **系统代理 (System proxy)** 选项。
2.  将其切换为 **自动配置系统代理 (Automatic configuration)**。
3.  同时，旁边的 **路由 (Routing)** 选项建议设置为 **绕过大陆 (Bypass mainland)**。这等同于其他软件的规则模式，能保证国内网站直连。
4.  此时，您的 Windows 系统图标栏中 v2rayN 的图标通常会变为红色（代表代理已开启），您可以打开海外网站进行验证。

*(注：如果您遇到了部分命令行或特殊软件无法连网的问题，v2rayN 同样支持开启 TUN 模式，可在设置中启用虚拟网卡，具体原理请参考[《什么是 TUN 模式》](/blog/what-is-tun-mode)。)*


## 版本说明

代理客户端、操作系统以及相关网络组件会持续更新，不同版本的界面、功能和配置方式可能存在差异。本文以当前可验证的信息为基础进行说明，实际操作时请以软件当前版本的官方文档和实际界面为准。
