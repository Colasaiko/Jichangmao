## 什么是 Quantumult X？

Quantumult X（常被玩家称为“圈X”）是 iOS 平台上功能最为强大的网络代理工具之一。与主打简单易用的 Shadowrocket（小火箭）不同，Quantumult X 提供了极其深度的自定义选项，包括节点策略组配置、强大的[分流规则](/blog/what-are-routing-rules/)（Rule）、请求重写（Rewrite）以及 MitM（中间人攻击）解密。

它非常适合那些不满足于简单翻墙，希望实现自动去除 App 广告、解锁流媒体区域限制、自动运行签到脚本等高级玩法的进阶用户。

> **提示**：Quantumult X 在非国区 App Store 售价为 $7.99 美元。国内 Apple ID 无法搜索到，你需要准备一个已充值的美区或港区 Apple ID 进行购买。

## 步骤一：导入机场订阅节点

如果你只是需要翻墙，导入节点是第一步：

1. 打开 Quantumult X 应用，点击主界面右下角的 **大风车（设置）** 图标。
2. 在设置菜单中找到 **节点（Nodes）** 区块，点击 **引用（URI）**。
3. 点击右上角的 **添加** 图标（或加号）。
4. 在 **标签（Tag）** 处随意填写你的[机场](/blog/what-is-airport-proxy/)名称（例如：微风网络）。
5. 在 **资源路径（URL）** 处，粘贴你从机场后台复制的 Quantumult X 专属订阅链接。
6. 打开 **解析（Parse）** 选项（非常重要，确保节点格式能被正确识别）。
7. 点击右上角的 **保存**，回到设置页，点击左上角返回主界面。
8. 此时系统会自动更新并拉取节点，在主界面长按右下角大风车，即可展开并查看所有已导入的节点。

## 步骤二：开启代理并选择模式

导入节点后，你需要选择一种代理模式才能科学上网。长按右下角的 **大风车** 图标，你会看到三种模式：

*   **全部直连（Direct）**：所有流量都不经过代理节点，相当于关闭了翻墙功能。
*   **全部代理（Proxy）**：所有流量强制走代理节点。适合在遇到严重网络阻断，或者需要全局伪装 IP 时使用（消耗机场流量较大）。
*   **规则分流（Rule）**：最推荐的日常模式。访问国内网站时直连，访问被墙网站（如 Google、YouTube）时自动走代理节点。

**开启代理**：
回到主界面，点击右上角的 **开关按钮**，系统会提示添加 VPN 配置，允许并验证 Face ID/密码后，顶部状态栏出现 `VPN` 图标即表示连接成功。

## 步骤三：进阶配置（重写与分流规则）

这是 Quantumult X 的灵魂所在。通过导入第三方大佬维护的配置文件（Config），你可以实现去广告和高级解锁。

1. 点击右下角 **大风车** 进入设置。
2. 划到最底部的 **配置文件（Configuration）** 区块，点击 **下载（Download）**。
3. 在弹出的输入框中，粘贴网上知名的懒人配置规则链接（例如墨鱼大佬或神机规则）。
4. 确认保存后，Quantumult X 会用这套高级规则替换掉默认配置。
5. （可选）如果你需要使用去广告的重写脚本，还需要在设置中的 **MitM** 选项里，生成并信任 Quantumult X 的 CA 证书，并开启 **MitM** 开关。

> **注意**：替换配置文件会导致你之前手动导入的节点丢失，你需要重新执行“步骤一”来重新绑定机场订阅。

## 常见问题解答 (FAQ)

### 1. Quantumult X 提示“证书不受信任”怎么办？
这是因为你开启了重写（Rewrite）或 MitM 功能，但没有在 iOS 系统中信任证书。
**解决办法**：去 iOS 的 **设置 -> 通用 -> 关于本机 -> 证书信任设置** 中，找到 Quantumult X 的证书并打开绿色的信任开关。

### 2. 怎么测速看哪个节点快？
在主界面，展开你的节点列表，点击右上角的 **[测速](/blog/how-to-test-node-speed/)** 图标。Quantumult X 会批量对所有节点进行延迟测试（通常基于 HTTP 请求，比单纯的 Ping 更准确）。数值越低（显示为绿色）代表延迟越小。

### 3. 它和 Shadowrocket 相比哪个好？
*   **Shadowrocket**：便宜（$2.99）、简单粗暴，支持的冷门协议极其丰富，适合 90% 只想看 YouTube 和网页的普通小白。
*   **Quantumult X**：昂贵（$7.99）、UI 更精致、支持编写 JavaScript 脚本、分流规则更强大，适合喜欢折腾手机、想要去广告的极客玩家。
