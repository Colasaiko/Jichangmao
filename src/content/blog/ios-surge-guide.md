## 什么是 Surge？

Surge 是苹果生态（iOS / macOS）中在本站测试的品牌中属于表现较好的选项、历史最悠久、也是价格最昂贵的网络工具。它最初仅仅是一个代理软件，但经过多年的迭代，如今的 Surge 更像是一个强大的“网络接管中心”和“开发者调试工具”。

Surge 的主要受众不是普通的小白用户，而是重度网络折腾玩家、开发者以及对网络稳定性有极高要求的高端用户。

> **提示**：Surge 在 App Store 可免费下载，但需要通过应用内购（IAP）解锁功能。iOS 版目前的售价高达 $49.99 美元（买断制，提供一定期限的免费更新），堪称代理软件中的“奢侈品”。

## 核心概念：Profile（配置文件）

与其他客户端简单导入一个 URL 就能用不同，Surge 的核心完全围绕着 **Profile（配置文件）** 展开。一个标准的 Surge 配置文件包含了：
*   **[General]**：通用设置（如接管 DNS、路由模式）。
*   **[Proxy]**：你的机场[节点](/blog/what-is-node/)列表。
*   **[Proxy Group]**：策略组（如：流媒体走 A 节点组，日常网页走 B 节点组）。
*   **[Rule]**：分流规则（决定什么域名走哪个策略组）。

## 步骤一：一键导入托管配置 (Managed Profile)

对于 90% 的[机场](/blog/what-is-airport-proxy/)用户，最简单的使用方法是直接导入机场提供的 Surge 托管配置：

1. 在你的机场后台（如微风网络），找到 **一键订阅** 区域。
2. 点击 **导入到 Surge**（或者复制 Surge 的订阅链接）。
3. 如果是在同一台手机上操作，系统会自动唤醒 Surge App。
4. Surge 会弹出一个新建配置的窗口，点击 **Download（下载）**。
5. 下载完成后，在 Surge 首页的左上角，点击配置名称，选择刚刚下载的这个新配置。
6. 点击主界面右上角的 **Start（启动）**，允许系统创建 VPN。

这就是最简单的“傻瓜式”用法。此时 Surge 已经接管了你的网络，并按照机场写好的规则开始分流。

## 步骤二：使用 Surge 模块 (Modules)

如果你导入了机场的托管配置，你会发现它是只读的，你无法在手机上直接修改里面的[分流规则](/blog/what-are-routing-rules/)。为了实现“去广告”或“网易云解锁”等高级功能，你需要使用 Surge 的独家利器：**模块 (Modules)**。

模块可以无视只读限制，直接覆盖并增强当前的配置文件。

1. 在 Surge 首页，向下滑动找到 **Modules（模块）**。
2. 点击进去后，你可以看到 Surge 官方自带的一些基础模块。
3. 如果要安装第三方的去广告模块，点击右上角的 **Install（安装）**。
4. 输入第三方模块的 URL（可以在 GitHub 上找到大量开源模块）。
5. 开启模块开关，Surge 就会在底层自动将该模块的代码合并到你的配置中。

## 步骤三：抓包与 MitM 解密

Surge 的另一大杀器是极其强大的网络调试功能。

1. 在主界面开启 **MitM（Man-in-the-Middle）**。
2. 根据提示生成并安装 CA 证书到系统，并前往设置信任该证书。
3. 回到主界面，点击 **Recent Requests（最近请求）**。
4. 你可以实时看到手机上所有的 App 发出了什么网络请求，甚至能查看到被解密的 HTTPS 流量内容。
5. 结合 **Scripting（脚本）** 功能，你可以针对特定的请求编写 JavaScript 代码，实现篡改返回结果（例如：把某个 App 接口返回的 `is_vip: false` 改为 `is_vip: true`）。

## Surge 与其他软件对比总结

*   **Surge vs Shadowrocket**：Surge 的底层网络引擎重构得极其精良，长时间挂后台不会断流，功耗控制极佳；而小火箭虽然便宜，但长时间高负载运行偶尔会发热或断连。
*   **Surge vs Quantumult X**：Surge 的 UI 更符合原生 iOS 规范，逻辑更严密；圈X 界面较为主观，但胜在便宜且支持了一些 Surge 不支持的“旁门左道”协议（如老旧的 SSR）。Surge 坚持不支持已被淘汰或不安全的协议。
