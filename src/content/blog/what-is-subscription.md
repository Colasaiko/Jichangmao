在您购买了网络代理服务（[获取了代理节点](/blog/what-is-node)）之后，接下来的第一步，通常是将这些[节点](/blog/what-is-node/)导入到您的手机或电脑中。

在现代代理服务中，您几乎不需要手动输入任何服务器 IP 或密码，这一切都依赖于一项核心技术：**订阅链接**。

本文将为您解释订阅链接的工作原理，以及如何正确获取并导入它。

## 什么是订阅链接？

**订阅链接**（Subscription Link），是一串由服务商生成的、包含了您账号专属信息和所有节点配置参数的独特网址。

**为什么需要订阅？**
一个服务商可能提供几十甚至上百个节点。如果让用户逐一手动输入每个节点的服务器地址、端口号和加密密码，不仅极其繁琐，而且极易出错。
通过订阅链接，客户端软件可以在一秒钟内，从这一个网址中批量拉取并解析出所有节点的配置信息。

此外，当服务商更换了某个节点的服务器 IP 或增加了新节点时，您只需要在客户端中点击“更新订阅”，软件就会自动同步最新的节点列表。

## 订阅链接通常包含什么？

虽然它看起来像是一个普通的网址（URL），但当您的客户端访问这个网址时，服务器会返回一长串经过编码的文本（通常是 Base64 编码或 YAML 格式文件）。
这段文本中包含了所有节点的技术参数。**请注意，这段文本中也包含了您的账号身份标识，因此绝对不要将您的订阅链接分享给他人，以免流量被盗用。**

## 如何获取并导入订阅链接？

**1. 获取链接**
登录您的服务商官网后台（通常称为用户面板），找到“一键订阅”或“我的订阅”区域。点击对应的按钮（如“复制订阅链接”），将其复制到系统剪贴板。

**2. 导入客户端**
打开您设备上的代理客户端软件。由于客户端种类繁多（如 Windows 上的 [Clash](/blog/mac-clash-verge-rev-guide/) Verge Rev，手机上的 v2rayNG 等），界面设计各有不同，但基本逻辑是一致的：
*   找到软件中的 **“订阅 (Profiles / Subscriptions)”** 菜单。
*   点击 **“新建”** 或 **“+”** 号。
*   将刚才复制的网址粘贴到 **“URL / 地址”** 栏中。
*   点击 **“下载 / 导入 / 更新”**。

*注：不同客户端的界面选项可能存在差异，导入失败时，请以当前软件版本的实际界面提示为准。*

## 什么是订阅更新？为什么会失效？

在使用过程中，您可能会遇到原本正常的节点突然全部无法连接的情况。这通常是因为服务商在后台更换了服务器 IP。

此时，您需要进行**订阅更新**：
在客户端的订阅列表中，找到对应的订阅项，点击“刷新”或“更新”图标。软件会重新向订阅链接拉取最新的节点配置。

**订阅失效的常见原因：**
1.  **套餐过期或流量用尽**：这是最常见的原因。请登录服务商官网检查账号状态。
2.  **本地网络干扰**：部分情况下，您的本地网络可能暂时无法解析服务商的订阅服务器域名，导致更新失败。可以尝试更换网络环境（如切换到手机 4G/5G 流量）后重试。
3.  **服务商维护**：订阅服务器本身可能正在维护，可稍后再试。

## 安全使用注意事项

订阅链接等同于您的账号密码。如果您的链接不慎泄露，或者您怀疑有人盗用了您的流量，请立即登录服务商官网后台，找到并点击 **“重置订阅链接”** 按钮。
重置后，旧的链接将立即作废，您需要将生成的新链接重新导入到所有设备的客户端中。
