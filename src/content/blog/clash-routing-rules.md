在理解了[什么是分流规则](/blog/what-are-routing-rules)之后，我们来看看如何在具体的客户端中应用它们。

以 Windows 端主流的 **[Clash](/blog/mac-clash-verge-rev-guide/) Verge Rev** 为例，服务商通常已经为您在订阅文件中写好了完善的底层分流代码。普通用户不需要学习编程去修改底层代码，只需要通过图形界面的“代理组 (Proxy Groups)”来进行可视化的规则配置。

## 什么是代理组 (Proxy Groups)？

打开 Clash Verge Rev 的 **“代理 (Proxies)”** 界面，您会看到除了最基础的国家节点列表外，上方通常还有几个特殊的卡片，比如：
*   **PROXIES (全局代理)**
*   **Netflix (流媒体)**
*   **ChatGPT (AI 服务)**
*   **Apple (苹果服务)**

这些卡片，就是服务商为您预设好的**代理组**。每一个代理组背后，都绑定了一大串特定的[分流规则](/blog/what-are-routing-rules)。

## 基础配置步骤

您可以通过点击这些卡片内部的选项，来告诉 Clash 遇到特定规则时，应该走哪条具体的节点。

### 1. 为海外通用流量选择节点
通常会有一个名为 `PROXIES` 或 `Global` 或 `自动选择` 的总代理组。
*   **操作**：在这个卡片里，选中您希望日常使用的节点（如 `香港 01`）。
*   **效果**：所有没有被特殊分类的海外网站，都会默认通过这个香港节点访问。

### 2. 为特定服务指定专属节点
某些服务对 IP 有特殊要求。例如，您希望日常上网用香港节点，但看 Netflix 必须用美国原生节点。
*   **操作**：在 `Netflix` 代理组卡片中，选中 `美国 01` 节点。
*   **效果**：如果服务商的规则库准确包含了 Netflix 的域名，当您访问该服务时，客户端会自动将流量引导至美国节点。注意，这依赖于规则库的准确性以及目标节点是否支持该流媒体服务。

### 3. 设置特定流量直连
比如您希望苹果的 App Store 下载速度快一点，不走代理。
*   **操作**：在 `Apple` 代理组中，选择 `DIRECT`。
*   **效果**：`DIRECT` 选项代表“直接连接”。当选中此项时，规则库中匹配为苹果相关的流量将尝试绕过代理，直接通过本地宽带连接，但这同样取决于当前规则对苹果域名的收录是否完整。

## 验证规则是否生效

如果您发现配置后，某个网站的加载速度异常或提示 IP 限制，您可以在 Clash Verge Rev 的 **“连接 (Connections)”** 面板中，实时查看该网站的流量是被哪个代理组接管的，从而判断您的设置是否正确生效。
