在了解了[什么是 TUN 模式](/blog/what-is-tun-mode)的原理后，如果您确实需要接管电脑底层的全部流量（例如为了让命令行工具或某些特殊软件走代理），您可以在 Clash 中开启该功能。

以 Windows 端的 **[Clash](/blog/mac-clash-verge-rev-guide/) Verge Rev** 为例，开启 TUN 模式需要以下标准步骤。

## 步骤一：安装服务模式 (Service Mode)

在绝大多数 Windows 环境下，由于 TUN 模式需要修改系统底层网络配置，通常需要先安装提权服务（Service Mode）。不过部分新版客户端可能会在开启时直接请求系统授权而无需手动安装，具体请以实际运行情况为准。

1.  打开 Clash Verge Rev 客户端。
2.  点击左侧导航栏的 **“设置 (Settings)”**。
3.  在右侧的主面板中向下滑动，找到 **“系统设置 (System Settings)”** 或 **“服务模式 (Service Mode)”** 区域。
4.  您会看到当前状态可能显示为“未安装”或一个红色的盾牌图标。
5.  点击旁边的 **“安装 (Install)”** 按钮。
6.  此时 Windows 可能会弹出用户账户控制（UAC）的授权窗口，提示您允许应用对设备进行更改，请点击 **“是”** 或 **“允许”**。
7.  安装完成后，状态图标通常会变成一个绿色的盾牌，提示服务已在后台静默运行。

## 步骤二：开启 TUN 开关

服务安装成功后，开启 TUN 模式就非常简单了。

1.  仍在 **“设置 (Settings)”** 界面中寻找。
2.  找到 **“TUN 模式 (TUN Mode)”** 的开关选项。
3.  将其切换为**开启 (开启状态通常会高亮显示)**。
4.  此时，建议将原有的 **“系统代理 (System Proxy)”** 开关关闭。因为 TUN 模式已经接管了底层流量，保留双重接管不仅没有必要，有时还会引发部分软件的死循环冲突。

## 验证 TUN 是否生效

您可以按下键盘上的 `Win + R` 键，输入 `cmd` 打开命令行窗口。
在黑框中输入 `ping www.google.com` 并按下回车。
如果出现类似于 `Reply from...`，说明底层的 ICMP 流量已被成功路由。请注意，ping 命令仅能作为基础的网络连通性参考，由于许多代理节点会主动丢弃或不支持 ping 包，即使显示超时也不代表网页无法访问。TUN 模式的最终是否生效，仍需以特定软件的实际联网状态为准。
